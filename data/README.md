# Data Sources

Synthetic source-style data for AI planner product discovery, model performance, and user impact prioritization.

- `entities.csv`: 36 AI feature records.
- `daily_metrics.csv`: 5,040 AI feature-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
